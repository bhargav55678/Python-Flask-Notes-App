# Flask Notes App

A simple Flask-based Notes application that allows users to create, view, edit, and delete notes.

## Project Overview

This project was developed as part of an internship task to demonstrate Flask web development.

The application uses Flask for routing and templates, Bootstrap for the user interface, and SQLite for storing notes.

## Features

- Create new notes
- View saved notes
- Edit existing notes
- Delete notes
- SQLite database
- Flask routing
- HTML templates
- Bootstrap responsive UI
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- Bootstrap
- Jinja2
